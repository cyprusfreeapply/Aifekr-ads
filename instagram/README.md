# اینستاگرام @neareastfarsi

موضوع: پذیرش دانشجوی ایرانی در دانشگاه Near East (قبرس شمالی). زبان محتوا: فقط فارسی.

## ساختار پوشه
- `profile.md` — اطلاعات پایه، مخاطب، ستون‌های محتوا (منبع اصلی همهٔ محتوا)
- `week-plans/` — برنامهٔ هر هفته
- `daily/YYYY-MM-DD.md` — گزارش و محتوای روزانه (کار زمان‌بندی‌شدهٔ ۸:۴۰ صبح به وقت قبرس)

## قواعد ثابت
- هیچ پستی بدون تأیید صاحب پیج زمان‌بندی یا منتشر نمی‌شود.
- هیچ عدد، قیمت، شهریه یا تجربهٔ دانشجویی ساختگی نوشته نمی‌شود؛ جای خالی با `{{...}}` علامت می‌خورد.
- بهترین ساعت انتشار (Metricool): ۱۰:۰۰ روزهای کاری، بعد ۱۸:۰۰. آخر هفته ضعیف‌تر.
